Empire & Ink

Complete Tech Stack (Version 1.0) — Simplified & Streamlined for Mughal Miniature AI Generation.

Core Tech Stack

Frontend Studio
  • React 18 + Vite 6
    Fast Single-Page Application with an instant interactive canvas and live code updates.
  • TypeScript + Tailwind CSS v4
    Type-safe components styled with curated Mughal color palettes.
  • Lucide Icons
    Crisp royal court iconography and clean SVG icons.
Backend & Auth
  • FastAPI (Python 3.12)
    High-speed async API coordinating AI models and workflows.
  • JWT + bcrypt Auth
    Secure token authentication and password hashing.
  • SQLAlchemy + Pydantic v2
    Type-safe database ORM and request data validation.
AI & GPU Engine
  • Flux 1 dev + Custom LoRA
    Generates authentic Mughal miniature brushwork and pigments.
  • Ollama (Qwen 3 8B)
    Local LLM enriching simple prompts with historical attire.
  • RealESRGAN + NVIDIA DGX
    Runs locally on DGX Spark, upscaling artwork to high-res.
Knowledge & DevOps
  • FAISS Vector Store
    Retrieves Mughal historical context via semantic search.
  • PostgreSQL + Disk Storage
    Stores metadata while saving image files by date (YYYY/MM/DD).
  • Docker + NGINX
    Containerized services with clean reverse-proxy routing.

Simple Generation Pipeline

1. User Enter Prompt
2. AI Enhances Historical Details (Ollama Qwen 3 + FAISS)
3. GPU Renders Miniature (Flux 1 dev + Custom LoRA on DGX Spark)
4. RealESRGAN Upscales & Delivers Artwork to Studio
